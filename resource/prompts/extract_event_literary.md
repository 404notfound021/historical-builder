# 文学作品事件抽取提示词

你是一位精通中国古典小说的研究者。请从以下小说原文中，识别并提取所有有**独立情节名称**的重要事件。

## 什么是"重要事件"

必须同时满足以下条件：
1. 有明确的情节边界，可作为独立叙事单元（如"元妃省亲""宝玉挨打""抄检大观园"）
2. 涉及两个及以上人物，推动故事发展或揭示人物关系
3. 在回目中或以固定称谓被提及的情节节点

## 什么不是事件

以下禁止作为事件输出：
- 日常起居：吃饭、睡觉、散步、请安
- 单独对话：两人闲聊、一问一答
- 心理活动：人物内心独白、梦境片段（除非是独立情节如"梦游太虚幻境"）
- 服饰描写、景物描写、诗词创作（除非构成独立情节）
- 琐碎动作：倒茶、梳妆、看书、写字
- 单人物行为：某人独自做某事，无他人参与或影响

## 输出要求

对每个事件，以 JSON 格式输出：

```json
{
  "事件名称": "宝玉挨打",
  "时间": "",
  "朝代": "清",
  "地点": "荣国府",
  "参与人物": ["贾宝玉", "贾政", "王夫人", "贾母"],
  "涉及势力": ["贾府"],
  "起因": "贾宝玉与忠顺王府优伶琪官交往，又因金钏投井事被贾环诬告",
  "经过": "贾政怒极，命人将宝玉按在凳上痛打。王夫人赶来哭劝，贾母赶到怒斥贾政",
  "结果": "贾政停手跪地认错，宝玉被抬回怡红院养伤，众人探望",
  "情节意义": "贾府父子矛盾的集中爆发，展现封建家长的专制与宝玉反抗性格",
  "出处卷目": "第三十三回"
}
```

## 注意事项

1. **只提取本章明确记载的事件**，不跨章推测
2. **事件名称**使用约定俗成的称谓，不带人物姓名前缀（"抄检大观园"而非"王夫人命抄检大观园"）
3. **参与人物写全名**，不用别名、小名
4. **起因/经过/结果**各控制在150字以内，重在准确完整
5. **空值填""**，不要写"无考"或"不详"
6. 每章通常只有 1-3 个事件，宁缺毋滥
7. 输出为纯 JSON 数组

## 补充规则

**同一事件不同章回出现时，必须使用完全相同的名称。** 例如"元妃省亲"散落多回，每次都应输出"元妃省亲"，不能输出"元春回家""贾妃省亲"等变体。
