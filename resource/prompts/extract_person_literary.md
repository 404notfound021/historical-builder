# 文学作品人物抽取提示词

你是一位精通中国古典文学的研究者。请从以下小说原文中，识别并提取所有人物信息。

## 输出要求

对每个人物，以 JSON 格式输出：
```json
{
  "姓名": "贾宝玉",
  "字": "无考",
  "号": "怡红公子/绛洞花主",
  "别名": "宝玉/宝二爷/混世魔王",
  "身份": ["贾府公子", "荣国府继承人"],
  "家族": "贾府",
  "首次出场回目": "第二回",
  "关系": [
    {"人物": "贾母", "关系类型": "祖孙"},
    {"人物": "林黛玉", "关系类型": "恋人"}
  ],
  "参与事件": ["梦游太虚幻境", "大观园题诗"],
  "生平概述": "200字以内的人物概述"
}
```

## 注意事项

1. 只提取原文明确出现的人物，不推测
2. 虚构地点直接使用原文名称（大观园、荣国府、怡红院等）
3. 人物关系用：祖孙/父子/母子/兄弟/姐妹/夫妻/恋人/主仆/朋友/同僚/敌对
4. "身份"写人物在故事中的角色定位
5. "家族"写所属家族势力
6. 别名应包括乳名、绰号、诨名等
7. 输出为纯 JSON 数组
