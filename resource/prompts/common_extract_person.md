# 通用人物抽取提示词

你是一位精通中国古代史的历史学家。请从以下古籍原文中，识别并提取所有历史人物信息。

## 输出要求

对每个人物，以 JSON 格式输出以下字段（如无明确记载则填"无考"、null 或空数组 []）：

```json
{
  "姓名": "姓名",
  "字": "字",
  "号": "号/别号/谥号（如'忠武侯'，无考填'无考'）",
  "其他名号": [{"类型": "谥号/庙号/追赠", "名称": "..."}],
  "朝代": ["朝代"],
  "生年": null,
  "卒年": null,
  "出生地": "原文中的出生地（古地名）",
  "出生地今名": "推测的今日对应地名（如'山东省临沂市沂南县'，无法推断填'无考'）",
  "卒地": "去世地（古地名，无考填'无考'）",
  "卒地今名": "去世地今日对应地名（无考填'无考'）",
  "历任势力": [
    {"势力": "蜀汉", "时段": "207-234", "角色": "丞相"}
  ],
  "官职": [
    {"名称": "军师中郎将", "时段": "208-214"}
  ],
  "爵位": [
    {"爵名": "武乡侯", "册封时间": "221"}
  ],
  "卒因": "被杀/病逝/战死/不详（无考填'不详'）",
  "关系": [
    {"人物": "关联人物姓名", "关系类型": "父子/君臣/同僚/朋友 等"}
  ],
  "参与事件": ["官渡之战", "赤壁之战"],
  "生平概述": "200字以内的生平概述"
}
```

## 注意事项

1. **只提取原文明确记载**的信息，不推测、不补充演义/小说内容
2. **姓名必须是本名**：原文中常以爵号/谥号/封号称人（如"高贵乡公髦""司马宣王""陈留王奂""秦王询"），你必须还原为真实姓名（如曹髦、司马懿、曹奂、曹询）。爵号和谥号填入对应的"爵位"和"其他名号"字段，不要填入"姓名"字段
3. **朝代用标准简称**：西汉、东汉、曹魏、蜀汉、东吴、西晋、东晋、隋、唐、宋、元、明、清。禁止使用"三国"作为朝代名
3. **历代势力**记录所属阵营及其时段；跨势力人物（如先仕蜀汉后归曹魏）以列表记录多个势力的任职时段
4. **官职**从原文提取所有曾任实际职务。只提取该人物所处朝代真实存在过的官职。严禁跨朝代编造（如三国人物不能出现元代/明清官职）
5. **爵位**单独记录，不与官职混合。爵位包括王、公、侯、伯、子、男等贵族等级
6. **关系类型**使用标准词汇：父子、母子、兄弟、夫妻、叔侄、祖孙、君臣、同僚、师生、朋友、敌对、举荐、幕僚、先祖
7. **出生地/卒地**写原文中的古地名，同时尽力推断并附今日地名
8. **生卒年**为公元年份整数（null 表示无考），避免使用年号纪年
9. **参与事件必须是有明确历史名称的重大事件**，标准：①有固定历史称谓（如"官渡之战"而非"与袁绍交战"）；②多势力/多人物参与；③史料中明确作为独立事件记载。不符合此标准的个人行为归入"关系"或"卒因"字段。严禁提取"被XX所杀""与XX交战""被赐死""被处死""征讨XX"等碎片化描述作为事件
10. 仅作为背景一笔带过、无任何具体信息的人物可以不提取
11. 输出为纯 JSON 数组，每个元素一个人物
